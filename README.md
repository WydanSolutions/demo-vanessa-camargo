# Demostración · Vanessa Camargo, organizadora de eventos

Demostración de una página de gestión para organizar bodas, preparada para
**Vanessa Camargo** y desarrollada por **Wydan Solutions**.

- **Las bodas, novios, invitados, proveedores y montos son inventados.**
- Funciona por completo en el navegador: no hay servidor ni base de datos detrás.
  Cada persona que la abre trabaja con su propia copia de los datos de ejemplo.
- Contraseña de la demostración: `1234`.
- La demostración está disponible por tiempo limitado.

### Qué se puede mirar
Todas las bodas, cada una con su paleta · Calendario y agenda · Clientes ·
Proveedores con estimador de costos · Servicios y presupuestos en PDF ·
Finanzas · Equipo. Dentro de cada boda: presupuesto, proveedores, invitados,
**salón y mesas**, tareas, cronograma del día, inspiración y acceso de los novios.
